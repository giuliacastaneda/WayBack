
# Projeto de Interface

## User Flow

O fluxograma a seguir representa o fluxo de interação do usuário com o sistema web, diferenciando os caminhos percorridos pelos dois perfis de usuário: 

- *Finder*: Descreve a navegação do usuário ao cadastrar itens encontrados e torná-los disponíveis para busca.
- *Seeker*: Descreve a navegação do usuário que busca por um item perdido, utilizando filtros de pesquisa e interagindo com as publicações dos Finders.

## Wireframes
 
### Tela - Home Page

A tela Home Page apresenta os componentes principais que seguirão de forma padrão em todas páginas:
- Cabeçalho: logo do sistema web e menu de acessos;
- Conteúdo: conteúdos referentes a pagina selecionada;
- Rodapé: Informações sobre os direitos autorais e ícones para as redes sociais.

Nesta tela, a logo do sistema e uma prévia de itens publicados recentemente para a procura pelos usuários, estão em maior evidência no conteúdo da página.

### Tela - Chat

Esta tela aparece após selecionada a opção *Contato* presente no item publicado, permitindo a conversação por meio de chat assíncrono entre o "Seeker" e o "Finder" para discutirem sobre o objeto. Podem discutir sobre as características básicas do item feita pelo "Seeker" para agilizar a devolução do item de forma rápida e segura, para identificar o real dono e sem a exposição de dados pessoais.

### Tela - Perfil

A tela de Perfil permite que o usuário gerencie suas informações cadastrais e publicações feitas anteriormente. Nesta tela, o usuário pode visualizar e editar seus anúncios publicados, com as opções para edição, atualização e desativação, garantindo controle total sobre os itens divulgados.
